# 障碍是静态实体，车辆撞上即停

首轮把树和灌木这类障碍当作静态实体：和地面一样不移动，求解时质量视为无穷大。车辆撞上就停住，不会把障碍撞走。

## Considered Options

- **障碍是静态实体**（选定）。与"不可通行"的既定说法一致（ADR-0005）；第三个冲量用例容易验：车停住、不穿透。
- **障碍是可移动刚体，按统一密度给质量、受地面摩擦**（推迟）。这是用户在讨论物理参数时提到的另一种可能。它引入动量传递和障碍自身的运动，需要额外的对照；等质量开始起作用的阶段再做。

## Consequences

- 首轮所有参与碰撞的东西里，只有车辆会动。这也是"首轮结果与质量无关"（ADR-0013）成立的前提之一。
