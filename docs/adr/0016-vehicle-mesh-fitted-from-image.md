# 车辆网格的缩放和摆位只依据原图证据

Hunyuan3D 输出的网格没有可靠的真实尺度。当前拟合同时搜索统一缩放、朝向和地面位置，依据原图 SAM 轮廓、DA3 逐像素深度与重建支撑面的接触。保存拟合前后的轮廓、深度、间隙和穿透诊断，并用无冲量物理试验检查初态。证据或门槛不合格时标记不可信。

首轮曾用特定车型尺寸做事后合理性检查。Spec #23 撤销这一决定：默认和可选路径均不读类别或实例尺寸参照，诊断也不再输出车型尺寸比例；尺度不确定性仅由图像目标剖面表示。

## Consequences

- 原视角轮廓 IoU 保留为失败条件之一（ADR-0014），当前首图门槛为 0.80。
- 深度残差和支撑间隙分别保存；无冲量试验沿用其接触与漂移门槛。
- 历史运行记录可按原有合同读取；旧拟合场景不能当作本轮无先验场景直接续跑。
