# 物理参数用常规假定值，地面是静态实体，物体一律按刚体处理

首轮的物理参数不从图像估计，用常规假定值并写进链路记录，每个用例固定同一组。地面是不移动的静态实体，求解时质量视为无穷大。物体一律按刚体处理：不反弹（恢复系数为 0），只保留与地面之间的摩擦。可移动实体的质量按"统一密度乘以模型体积"得到。

## Considered Options

参数来源：

- **常规假定值**（选定）。整车质量、砾石路面的摩擦系数各取一个文献里的典型值。首轮要回答的是"给定参数时解算对不对"，不是"参数估得准不准"。
- **从图像估计**（否决）。没有可靠办法。
- **以后从视频里反推**（推迟）。这是 proposal 的 Phase 3。

质量的约定：

- **地面质量视为无穷大**（选定）。即物理引擎里的静态物体：任何力都不会使它移动，也就是游戏引擎里对地面的处理方式。
- **场景实体统一密度，按模型体积给质量**（选定，用于可移动实体）。
- **按车型查真实质量**（否决）。依赖针对这张图的知识。

接触的约定：

- **刚体、不反弹、只有与地面的摩擦**（选定）。车辆与障碍的接触按"不反弹、不设摩擦"记录。
- **带弹性的接触**（否决）。首轮不需要。

## Consequences

- 首轮三个用例的结果都与质量无关：按"速度变化"定义用例时，抛物线和摩擦减速只取决于重力加速度和摩擦系数，撞上不移动的物体只取决于恢复系数。所以密度取多少不影响首轮验收，它只在以后有可移动实体互相作用时才要紧。
- 空心物体（如汽车）按统一密度会偏重，这一点在质量开始起作用的阶段再处理。
- 障碍（树、灌木）是静态实体，见 ADR-0015。
