# 首轮目标是单图自动建场，链路打通只是途中关口

首轮要验证的是"从一张精选的第三人称驾驶游戏截图，经自动管线得到可驾驶的局部三维场景"。给定可用的三维状态之后接通车辆物理、代理画面和异步视频，是实现这个目标途中必须通过的关口，单独通过不算首轮目标完成。

## Considered Options

- **首轮目标 = 单图自动建场**（选定）。建场是这条路线区别于"人工搭场景再接渲染器"的地方，也是风险最大的地方，所以它才是要验证的东西。
- **首轮目标 = 给定三维状态后接通物理与视频链路**（否决作为目标，保留为关口）。它绕开了建场，通过了也不能说明"一张图能变成场景"。验收时建场结果和链路结果分开记录，避免把后者的成功误报成前者的成功。

## Consequences

- 不使用 coding agent、LLM，也不使用针对该图预制的场景与车辆资产；允许预训练视觉／3D 模型补全不可见部分。
- 首轮不训练神经动力学模型，不要求高保真视频实时输出。
