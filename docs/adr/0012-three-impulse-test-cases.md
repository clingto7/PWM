# 首轮测三种冲量：斜抛、滑行、撞向路旁障碍

首轮的动作只有一种形式：对静止在路面上的车辆施加一个冲量。固定测三个用例，每个对应一条解算判据（ADR-0008）。

1. **斜抛**：斜向上、朝远离相机方向的冲量，作用在质心上，车做斜抛运动后落回路面。对照抛物线：滞空时间 2·v_z/g，射程 v_x·T。
2. **滑行**：沿路面方向的冲量，车滑行到停。对照摩擦减速：加速度 μg，滑行距离 v²/(2μg)。
3. **撞向障碍**：朝路旁灌木或树的冲量。检验与障碍的接触不穿透。

## Considered Options

- **固定三个用例**（选定）。
- **第一个用例用"从 1 米高处自由落体"**（否决，agent 的初始建议）。建出来的初始状态里车停在路面上，把车抬到 1 米高等于改了场景。改成斜向上冲量，同样能得到可对照的抛物线。
- **随机采样一批初速度和方向**（推迟）。等流程稳定后再加。
- **只做一个用例**（否决）。覆盖不了三条判据。

## Consequences

- 用例按"速度变化"定义，冲量等于质量乘以速度变化。这样用例不依赖质量的取值。
- 冲量作用在质心上，车不翻滚，抛物线才适用于整车。翻滚的情况需要额外的对照，首轮不做。
- 冲量方向取朝远离相机的一侧，保证车留在画面内。相机离地 1.69 m、俯角 7.6°，画面上沿只到约 24° 仰角，跳得太高会出画。
