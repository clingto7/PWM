# 原图中的车辆从场景中分离，车位用拟合的地平面填补

输入图里的车是重建场景的一部分。要让车动起来，必须把它从场景几何里分离出去：车辆区域改由 Hunyuan 网格表示，按原位置摆放；它原来挡住的那块路面不存在，用近处拟合出的地平面补上。这是自动建场中唯一一处"补看不见的几何"。

## Considered Options

- **用拟合的地平面填补**（选定）。这张图里车位下面是平直路面，平面先验足够，而且结果可检查。
- **用生成模型补全**（推迟到后续阶段）。首轮没有必要引入一个生成环节。
- **保留空洞**（否决）。车一开走就会露出空洞，深度和掩码都会出错。

## Consequences

- 分离车辆时，它的图像区域要同时从碰撞几何里去掉，否则车位会被判成障碍。
- 这是 agent 提出的默认做法，用户在确认整体流程理解时没有提出异议。
