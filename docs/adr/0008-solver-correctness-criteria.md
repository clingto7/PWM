# "解算正确"的判据是不变量加解析对照

首轮没有用户输入，也没有真实轨迹可对照，所以用两层判据验收求解器的输出：一层是不变量检查，一层是和手算公式的解析对照。

## Considered Options

- **不变量加解析对照**（选定）。不变量说明"没有明显出错"，解析对照说明"算得对"。
  - 不变量：车辆与地面、障碍不穿透；最终停在地面；能量不凭空增加；同样的输入得到同样的轨迹。
  - 解析对照：落地前的抛物线；给定摩擦系数下的滑行减速，和手算公式比较。
- **只看不变量**（否决）。只能说明没出错，说明不了算得对。
- **再加第二个求解器交叉**（推迟）。同一场景用另一个求解器（如 MuJoCo）再跑一遍，留到以后。

## Consequences

- 解析对照要求摩擦系数等物理参数是已知的假定值；参数来源另行决定。
- 容差数值等第一次测量之后再定。
