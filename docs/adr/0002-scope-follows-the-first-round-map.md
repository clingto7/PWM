# 研究设计的口径跟随首轮原型，proposal v2 是长期愿景

研究卡片和实验计划按决策地图（issue #1）的首轮口径来写。proposal v2（学习式 GNN 动力学、接入视频模型并实时化、从真实视频反向对齐）是长期愿景，列为后续阶段，不写进首轮承诺。

## Considered Options

- **按首轮原型的口径写**（选定）。首轮是一个范围明确的切片：单张驾驶图、自动建场、无训练动力学、代理信号。口径和实验对得上，验收才写得具体。
- **按 proposal v2 的全量口径写**（否决）。把学习式动力学和视频模型实时化算进本轮，等于同时赌三件没验证的事，任何一处失败都说不清是哪里的问题。
