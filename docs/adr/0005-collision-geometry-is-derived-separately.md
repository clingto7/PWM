# 碰撞几何与渲染表示分开，碰撞几何由深度自动导出

用于物理求解的几何和用于生成代理画面的几何是两套。碰撞几何由 DA3 的深度自动导出：一张地面高度图，加上车辆的简化体（包围盒或凸包）。它们不是手工资产。两套几何靠同一个车辆位姿绑在一起：动力学更新位姿，渲染按位姿画，碰撞按位姿算。

动力学的每一步要向场景问两件事：车轮下面某处地面多高，车辆现在有没有插进什么实体。求解器不回答这两个问题，只负责知道答案之后车辆怎么动。高斯回答不了这两个问题：它是半透明的模糊斑点，没有里外之分；不知道自己是路面、草还是树干；而且只有照片里看得见的表面才有。

## Considered Options

碰撞几何的来源：

- **高度图加车辆简化体**（选定）。这张图是平路，高度图足够；查询便宜，结果可检查。
- **从高斯里抽网格或 SDF 做通用碰撞**（首轮否决）。它的通用性在这里用不上，噪声却全收下。
- **直接对高斯做模拟**（否决）。这是 PhysGaussian 的路线，适合雪、泥这类软体连续介质，不适合一辆刚性车在路上开。

障碍的判定：

- **按高度图自动判定**（选定）。高出地平面超过阈值的格子算不可通行，树和灌木自然被挡住。纯靠几何，不需要识别物体类别。草丛会产生噪声格子，阈值单独记录。
- **全部可通行，植被只当背景**（否决作为首选，保留为回退方案）。车会穿过灌木、开进树线，这种穿模会进入代理信号。如果高度判定的噪声处理不好，首轮退到这里：植被只参与渲染，不做实体。
- **由人指定哪些物体是障碍**（否决）。违背无人工建场。

## Consequences

- 回退到"植被只渲染"的触发条件，等第一次量出噪声水平后再定。
- 渲染表示具体怎么画，见 ADR-0009；本决定只确立了"两套分开"。
