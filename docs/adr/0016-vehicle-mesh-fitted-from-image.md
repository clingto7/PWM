# 车辆网格的缩放和摆位从图像自动拟合，车型尺寸只做合理性检查

Hunyuan3D 输出的车辆网格是归一化的，不知道真实大小。首轮把缩放、朝向、位置三个量一起拟合：让网格从原图相机看过去的轮廓与 SAM 的车掩码最吻合，同时深度与 DA3 的深度一致，并约束车轮落在拟合出的地面上。拟合结果用该车型的真实尺寸做一次合理性检查，检查结果写进链路记录。

## Considered Options

- **自动拟合为准，车型尺寸做合理性检查**（选定）。拟合不依赖"认得这是什么车"，与自动建场的目标一致；尺寸检查用来兜住 DA3 在车身上深度出错的情况。
- **只做自动拟合，不做检查**（未单独采用）。少了兜底。
- **按车型查真实尺寸来缩放，只拟合位置和朝向**（否决作为方法）。依赖针对这张图的知识，换一张图就不成立。agent 在第一轮讨论里默认的是这种做法。

## Consequences

- 轮廓 IoU 是失败条件之一的测量量（ADR-0014），门槛待定。
