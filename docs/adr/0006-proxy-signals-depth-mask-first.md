# 代理信号先做深度和实例掩码，光流后置，首轮不含颜色

代理信号分两批：第一批是深度和实例掩码，用现有数据就能生成；光流放第二批。首轮的代理信号不含 RGB。

## Considered Options

- **先深度加实例掩码，光流后置**（选定）。光流主要服务视频模型的跨帧运动锁定，而视频模型是后置环节，不该阻塞建场和物理的主线。
- **三个通道一起上**（否决）。会把后置环节的问题提前带进来。
- **带粗糙 RGB**（推迟）。粗糙 RGB 对最终画面的帮助或干扰，是 proposal 议题 3 的消融实验要回答的问题，接视频模型时再测。

## Consequences

- 验收方式：同一段动作序列重放后信号序列一致；并抽查几何（掩码覆盖情况、遮挡切换时刻的深度跳变）。
- 代理信号不带颜色，意味着后续接视频模型时，外观只能来自参考图。这会限制可选的视频模型，到那一步再讨论。
