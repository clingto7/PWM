# 首轮的失败条件

出现下列任一情况，说明"单图自动建场"这条路在首轮没有走通。每条配一个测量量；数值门槛等第一次测量后回填。

| 失败条件 | 测量量 | 门槛 |
|---|---|---|
| 车辆网格按原图摆位、缩放后，轮廓和图里的车对不上 | 投影轮廓与 SAM 车掩码的 IoU | 待定 |
| 地面平面拟合在可信范围内不成立 | 拟合残差 | 待定 |
| 障碍判定把路面误判成不可通行，或噪声大到分不开，且回退到"植被只渲染"后代理信号仍不可用 | 路面格子中被判为障碍的比例 | 待定 |
| 任一用例的解算违反不变量，或对不上解析对照 | 最大穿透深度、能量增量、与解析解的偏差 | 待定 |

## Considered Options

- **这四条**（选定，用户确认可以增删，目前未改）。
- **现在就填数值门槛**（否决）。还没有任何测量，填出来的数是编的。
