# 场景管线各阶段可替换并独立比较

跨图阶段需要对视觉观测、场景重建与拟合、物理解算、渲染分别替换方法并比较结果，不能继续让一个运行脚本持有 PyBullet 建场、解算和光栅渲染的全部细节。各阶段以保存并校验的产物衔接：原图形成视觉观测，视觉观测形成与具体引擎无关的场景，场景和动作形成轨迹与接触结果，渲染方法消费同一场景和轨迹。顶层运行入口只编排阶段；渲染方法不修改场景或其他阶段的记录。

视觉观测内部有可分别选择的主体检测与分割、深度与相机估计、主体网格重建；场景拟合、物理解算和渲染也分别有可替换接口。同一个接口的不同实现须遵守共同输入输出约定，以便只替换一种方法并复用其余阶段产物。比较某个方法时先固定其上游产物，另外保留端到端运行，以区分单模块效果和模块组合效果。每次运行记录实际选择、版本、参数和输入输出哈希。

本阶段先落实共同接口并迁移已有实现；光栅与 Gaussian 渲染已有两种实现，可用于检验切换。SAM 3 分割、Depth Anything 2 深度和学习式动力学等可以之后分别接入，不要求本阶段同时落地。首轮实际消费的是 DA3 Nested、SAM 2.1 Tiny 产生的车掩码和 Hunyuan3D 2.1 车网格；DA2 Small 只在早期探索中运行，SAM 3 分割没有运行记录。另有 SAM 3D Objects 的预检记录，它是不同的物体三维模型，也未执行推理。

顶层入口应从单张原图自动执行视觉观测、场景构建、物理状态转移和代理视频渲染，记录每阶段及全链路墙钟耗时，包含模型加载、推理、数据转换和产物写入。现有 DA3 是默认深度与相机实现；DA2 的相对深度不与 DA3 同时进入同一次建场。未来选择只输出相对深度的实现时，接口须声明其尺度和相机能力；缺少建场所需米制深度或相机参数时，须经过额外的尺度与相机估计步骤或明确失败，不得默默把相对值当作米。

本阶段自动链交付到可交互场景、状态轨迹和代理视频。运行入口用固定且不依赖主体类别的动作脚本产生可重复状态转移，接口允许后续由外部传入动作序列。精细渲染保留为消费场景、轨迹与代理信号的后续可替换阶段，本阶段不要求实现。
