# 交互范围等于重建范围，用隐形墙约束

首轮不另外定义"可行驶区域"。车辆能到达哪里由建出来的几何直接决定；同时车辆不能驶出重建出可信几何的区域，到边界由隐形墙挡住，范围外只显示天空色。图片里给到哪里，就交互到哪里。

## Considered Options

- **重建范围加隐形墙**（选定）。图里本来不存在的东西做不出来，这是单图路线固有的边界，首轮如实声明它。
- **预设可行驶区域走廊**（否决）。另外画一条"允许通过"的走廊是多余的一层：路面和草地一样平，那就都能开。原词条"可行驶区域"因此改名为"建场范围"。
- **无限平地**（首轮否决）。高度图向外无限延伸，车能开出去，但景物不跟着延伸，开到树线外回头看到的是空的。一开出去就暴露背景只有正面，会把注意力引到首轮不打算解决的问题上。
- **用生成模型向外补场景**（推迟到后续阶段）。

## Consequences

- 建场范围是正前方约 95° 的扇形，可信半径约 27 米（依据见 ADR-0003 的深度实测）。60 km/h 开 1.6 秒就到边界，掉头面向背后时没有重建内容。这是首轮的明示限制。
- 范围内车辆能开到哪里，由碰撞几何决定（ADR-0005）。
